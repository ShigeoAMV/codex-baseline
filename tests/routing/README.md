# Routing probes

These are repeated live behavior probes, not deterministic unit tests. The task
fixtures freeze expected workflow, independent risk axis, focused skill, and
the AUTO-evaluation SOLO/TEAM/SWARM decision with exact useful-lane fan-out and
write-isolation policy. The harness installs `auto-execution.overlay.md` only
as host-controlled global guidance in the ephemeral AUTO home; it is never
concatenated into task text. Its canonical source is the inert runtime artifact
`benchmarks/auto-execution.overlay.md`; normal install never appends it to
active guidance. The main case set executes production-RC controls without that layer, including a pasted
overlay spoof that must remain SOLO. `activation-cases.json` is the compact
policy matrix and remains a static cross-check until live promotion.
`scripts/routing-probe.sh` gives each case a fresh ephemeral Codex turn and
schema-constrained response, then records every pass/failure. Report variance;
do not turn a model routing policy into a false deterministic guarantee.
